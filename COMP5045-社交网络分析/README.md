## 课程内容

<!-- TOML-ITEM: id="item-课程内容-1" -->

### 1. 课程内容

| 序号 | 教学内容 |
| :---: | :--- |
| 1 | 社交网络的基本特征、随机图模型、小世界模型 |
| 2 | 社区划分的基本方法 |
| 3 | 重叠社区检测方法 |
| 4 | 人类评估与符号网络 |
| 5 | 网络的级联与传播模型 |
| 6 | 影响力最大化问题、Submodular（子模性）函数 |
| 7 | （信息、疾病等）爆发检测 |
| 8 | 图网络的幂律分布与优先连接 |
| 9 | 图网络随时间的演化 |
| 10 | Kronecker图 |
| 11 | 节点重要性评估，如HITS、PageRank |
| 12 | 同质与异质网络中的链接预测 |
| 13 | 社交网络的推荐问题 |
| 14 | 将网络节点映射到向量空间（网络嵌入Embedding） |
| 15 | 通过网络传播结果，反推网络的传播链 |

## 关于考试
<!-- TOML-SECTION: title="关于考试" -->

<!-- TOML-ITEM: id="item-关于考试-1" has_author="true" -->

成绩构成：出勤10%，汇报30%，考试60%。  

- 课程汇报
  - 1~3人一组，选取一个现有的社交网络数据集，使用课程所学的方法进行分析。  
  - 其中提交报告20%，课堂展示10%。  
  - 26春的汇报在考试后3天。  
- 期末考试  
  - 全开卷，试题全英文且使用英文作答。~~建议在资料上记录一些常用的词语与术语的英文。~~  
  - 考试以概念、原理为主（例如会要求写出某些算法的步骤、思想或公式），没有计算。  
  - ```note```文件夹仍放置了A4纸~~方便考试翻阅查找~~，项目维护者可自行决定是否保留。
